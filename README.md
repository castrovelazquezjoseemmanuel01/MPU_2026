Es importante mencionar que en la carpeta de software no se adjuntaron los archivo pertenecientes 
al Z80 worckbench debido a que implementar el codigo en este simulador implica no utilizar el sis-
tema diseñado; es decir Z80 worckbench no permite configurar el puerto al que se conecta los peri-
fericos.

Ademas al intentar simular con Z80workbench, para cada comenzar la primera impresión se trababa 
la mayoria de veces.

Para solucionar esto se hizo uso del Z80 simulador IDE desarrollado por OshonSoft, que es al cual
pertenencen los archivos generados.

La carpeta Hardware_Act1 contiene el esquematico del sistema implementando logica AND y lineas de
conexión.

La capeta Hardware_Act1_1 contiene el esquematico del sistema implementando logica NOR, a demas
se implementaron nodos para mejorar la vsisibilidad de las conexiones y componentes.
